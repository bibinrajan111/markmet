# Markmet (Next.js)

Redesigned interactive marketing website built with:

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
- shadcn/ui-inspired component primitives
- Motion (Framer Motion)
- Lenis smooth scrolling
- Lucide React icons

## Run locally

```bash
npm install
npm run dev
```

## Routes

- `/`
- `/about`
- `/services`
- `/services/[slug]`
- `/contact`
